# 功能模块

> 客户端导航当前注册 **14 个应用**（契约 `contracts/apps.json`），其中 **13 个开放**、`ai` 入口保留；服务端拆成 **15 个域**
> （`src/modules/`）。两边不是一一对应：例如「影视」应用同时用到 `video` 与 `videoPlayer` 两个域。

## 客户端应用（14 个注册 / 13 个开放）

## 几个功能域的细节

### 相册

- **拍摄时间**优先 EXIF → 文件名日期 → 文件修改时间，逐级回落。
- **相册**可配「自动收录」规则：按头像 / 场景 / 日期区间挑，命中任意一条就自动进册，**之后新增的照片也按同一套规则自动进来**；改规则只增不减（要移走得手动「移出相册」）。
- **智能相册**分「场景 / 人脸」两段，顶栏「分析 20 张」分批推进；人脸阈值可用环境变量 `COLANAS_FACE_THRESHOLD` 调。
- **时光对照**：同一个「月-日」跨年并排展示，优先锁定同一个人物。
- **数据隔离**：相册按用户隔离，别人看不到你的相册。

### 影视

- 剧集识别：库根下建「剧名」目录，文件名带 `S01E02` / `1x02` / `第3集`，扫描后自动归集；点剧进入按季分组的选集页。
- **观看进度**按账号保存（别人看不到）；影视首页「最近在看」列最近 6 条，点卡片直接回到剧情。
- **NFO 冲突合并**：「用户手改优先」——自动刮削不会覆盖用户改过的字段。
- **下载完成自动入库**并触发刮削（文件监控订阅 `.nfo` 变更）。
- **原画直通**：`original` 档不做 HDR→SDR、视频流 `-c:v copy`，只把容器换成 fMP4，DV / HDR10+ 动态元数据原样送到显示端；音轨能安全封装时一并 copy。
- **响度归一**：库级开关同时作用于转码、原片直连与离线下载；直连由播放器套 `dynaudnorm`，转码由服务端套。它压的是动态范围，不是统一到固定 LUFS 目标。

### Android TV

- 顶部 tab + 大屏版面：↑/↓ 逐行移动焦点，到最顶才回 tab；返回先回当前栏目的 tab，在 tab 上连按两次才退出。
- 播放器键位：↓ 唤出操作栏、再按 ↓ 进按钮行选字幕 / 音轨 / 画质；← → 跳时间；OK 隐藏时暂停/继续、显示时收起操作栏；返回退出播放页。
- 按视口等比缩放，网格列数自适应，4K 电视能看到更多行。
- 按电视上报的 HDR 能力直连 DV / HDR10+ 原片，支持时不转码；能力不足才回落服务端色调映射。

### 音乐

- 歌词优先读同目录同名 `.lrc`（支持一行多时间戳与 `[offset:]` 校正），其次读音频内嵌歌词（mp3 USLT、flac LYRICS、m4a ©lyr、ogg/opus 注释）。
- **简繁与跳字搜索**：可按简繁两种字形检索。

### 文件

- 所有路径都是「相对文件根」，`..` 越界一律 400。
- 上传在「传输」页，已存在且同尺寸直接秒传；断点续传由服务端已收分片决定。

### 终端（受限）

- 只读白名单命令：`pwd` / `ls` / `dir` / `df` / `free` / `ps` / `tasklist` / `uname` / `whoami`。
- 不做管道、重定向、变量替换：服务端用 `execFile` 直接执行（**无 shell**），参数最多 16 个、5 秒超时、输出 64 KB 截断，工作目录限制在文件根内。
- 需要 `system:write` 权限。

### 下载器

- 随包内置 transmission-daemon 与同源 Web UI 代理；也支持连接用户自己填写的 Transmission RPC。
- 退出应用前先 `torrent-stop` 发 `stopped` 公告再停进程，内核热重启不打断做种。

### 账号与权限

- 子账号按 scope 授权（如 `photo:read`、`backup:write`），不要给无关账号 `*`。
- 2FA 密钥在服务端加密存储，明文只在开启时展示一次。
- 看到 403 或某个页面没数据，通常就是当前账号缺对应 scope。
