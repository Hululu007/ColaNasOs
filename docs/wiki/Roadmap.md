## 主干已落地（待发版）

当前公开安装包仍是 **v1.3.3**，主干版本已推进到 **1.3.13**。以下改动已进主干，等下一个安装包分发：

| 方向 | 内容 |
| --- | --- |
| TV 硬解与兼容性 | Media3 隧道模式（同步交给 SoC，4K / HDR 不掉帧）、解码器回退（DV / HEVC 10bit 不黑屏）、24p 匹配刷新率；无平台解码器音轨主动报错并切服务端转码；Hybrid Composition 真实 Surface 保住 HDR / 杜比元数据 |
| TV 交互 | 逐行焦点、双击返回退出、播放器键位重排、按视口等比缩放与自适应网格 |
| 原片直连 | 电视按 HDR 能力放行 DV / HDR10+；原画档只换容器不重编码，保留 HDR 元数据 |
| 响度归一 | 库级开关下发到直连播放器；转码 / 直通 / 离线下载三条链路同口径 |
| 相册 | 人物列表批量隐藏 / 并组 / 解散，单个人物右键直接隐藏 |

## 近期重点

1. **播放器链路**（最影响体验）：转码首片速度、AV1 首片时长、拖动与连按的边界条件、停滞自愈的覆盖面。
2. **服务端续转唤醒**：会话转完一段停手后，客户端能催转，但服务端侧的自动唤醒还应更稳。
3. **鸿蒙端**：工程骨架已就位，等 `flutter_ohos` 与主线版本对齐后出安装包。
4. **Apple TV**：官方无 Flutter 支持，当前保留 Swift 壳 + 桥接方案，待验证。
5. **多语言**：13 种语言已登记，翻译流水线就位（见 `docs/i18n/翻译工作流.md`），其余语言待人工翻译。

## 完成定义（DoD）

一份改动要算「做完」，按 `docs/10-DoD.md` 的四类 DoD 自查：

| 类型 | 要点 |
| --- | --- |
| 内核任务 | 编译 0 error；迁移可前滚可回滚；不破坏单实例与 ABI；错误码登记 |
| 域模块任务 | 端到端回归通过；对照功能覆盖台账逐项打勾；单域故障不影响其它域 |
| 客户端页面 | `flutter analyze lib` 全量 0 error；窄屏/宽屏都验；空态/错误态/加载态齐全；i18n 键齐全 |
| 文档任务 | 同步更新对应分册与 Wiki；命令可复制执行；结论有证据 |

评审清单（PR 模板）在 `docs/10-DoD.md` §5。
